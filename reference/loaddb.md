# Load the table of an EDA object from the database

stores the result in one of the class slot

## Usage

``` r
loaddb(object, ...)

# S4 method for class 'Eda'
loaddb(object, ...)
```

## Arguments

- object:

  An [Eda](Eda-class.md) object.

- ...:

  Further arguments passed to methods.

## Value

The [Eda](Eda-class.md) object with one or several slots filled.
